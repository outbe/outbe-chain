# P3 interactive DKG / repository signer proof

Test source `b4bfc6f6f3acc7664254daf204757888bd1866b7`; base `11bd6242e1f513850f2b56e9b360082fbfc75aa5`. Production source is unchanged.

The new test drives four existing durable interactive genesis actors over the existing in-memory P2P mesh. Each participant receives its local Share and the same public Output; no centralized `bootstrap_dkg*`/`dkg::deal` fixture creates the material. It then runs the existing durable live reshare paths with one old validator removed and a newcomer added. The removed member runs dealer-only; the harness selects verified old-dealer logs and injects the same canonical set into each player. This is real actor/protocol/crypto behavior with a mocked transport and injected finalized-log feed, not live chain finality or production E2E.

Existing Cargo library build was used only to obtain exact link artifacts for the verifier; this is not a new consumer/production E2E claim.

Limitations: the native subject payload is the fixed framing fixture `native Review Accept bytes`, not a real Git commit/package; actual exact Git Review preparation is a separate adapter scenario already included in the66 tests. This core test does not prove current-chain checkpoint authorization, live actor-node integration, publication, deployed key provenance, cross-process key isolation or that secrets have never been gathered elsewhere. The harness holds participants' local results for assertions; no full group secret is reconstructed. The fixture uses existing deterministic runner deadline600s, while dealer secrets still come from the production durable actor path. No production changes and no task acceptance reviews/closures. Signer/control wire, sidecar collector, automatic bootstrap, Merge and full P0-P8 E2E remain incomplete; D3 remains unapproved. Initial development fixture compile errors (RepositoryKey conversion and cloning indexed partials) were corrected before this frozen source, not counted as successful evidence.
