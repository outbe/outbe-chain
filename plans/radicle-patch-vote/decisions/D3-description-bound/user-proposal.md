# На согласование: 255 UTF-8 байт для описания governments

Предлагаемое изменение: одинаковый максимум **255 UTF-8 байт** для поля description
в governments genesis descriptor, Rust validator, Python seeder и утверждённом плане.
Описание сохраняется буквально; слишком длинное значение отклоняется при подготовке
genesis. Данные не обрезаются. Правила native Heartwood остаются существующими.

Причина: сейчас утверждённый design.md §5 и код genesis разрешают1024 байта, а native
Radicle Project constructor/reader разрешает255. Фактический тест на source
`a0c104079c24525bd4d5e9fd4374aedc76c57df4` показал: описание256 байт успешно проходит
OGD1 encoder/decoder, но native Project отвергает его. Production Python seeder
также принимает256 и1024 байта. Из такого допустимого genesis input текущий native
identity создать нельзя.

Три независимых агента, не авторы предложения, до собственного verdict не читали
чужие отчёты. Каждый проверил одинаковые source/spec/proposal hashes, повторил
Rust diagnostic и независимо проверил Python seeder:

| Проверка | Проблема | Вариант255 |
| --- | --- | --- |
| [R1](reviews/R1.md) | подтверждена | технически корректен, только после явного согласия |
| [R2](reviews/R2.md) | подтверждена | технически приемлем, только после явного согласия |
| [R3](reviews/R3.md) | подтверждена | рекомендован, только после явного согласия |

Это decision checks, не acceptance reviews и не разрешение реализации.

После согласия: исправить указанные validator/seeder/spec/self-check и граничные
тесты255/256, включая UTF-8; максимальный OGD1 descriptor станет352 байта вместо1121.
Для значений<=255 bytes/hash остаются прежними. Затем записать новое exact-SHA/spec
evidence и заново провести три полных P0 acceptance reviews; P1/P5 оценить по фактическому
relevant diff и affected regression checks. Исторические evidence/PASS не переписывать.

Риск: ранее допустимый genesis с описанием256..1024 байта новый validator перестанет
принимать. Наличие таких deployed inputs не проверялось; предложение не разрешает
менять уже созданную genesis/историю или выполнять deployment.

Production limits и утверждённый spec ещё не изменены. Зависимая реализация bootstrap
остановлена до явного ответа пользователя. Альтернативное расширение native Project
до1024 здесь не выполняется и не считается одобренным fallback.

Вопрос для согласования: изменить утверждённый максимум описания governments
с1024 на255 UTF-8 байт указанным способом?
