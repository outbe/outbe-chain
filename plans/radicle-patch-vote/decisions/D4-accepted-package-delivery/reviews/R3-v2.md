## Decision assessment

The core assessment from my own v1 review remains valid: a fresh pinned managed repository can read accepted receipts but lacks Outbe-local witness/package bytes, and native fetch cannot deliver them. The frozen fourth-store test is negative proof of the gap, not positive catch-up. The approved design/P6/P7/P8 requires accepted historical delivery, and no smaller complete supported existing path was found. Adding a bounded public archive message type to the existing authenticated channel and protected local socket is an Outbe delivery integration, not D2/native storage/fetch redesign.
