# Исходные заметки

Рабочие документы MVP в том виде, в каком они велись. Адреса серверов заменены
на `<amd-host>`, `<intel-host>`, `<build-host>`.

| Файл | Что |
|---|---|
| `plan.md` | исходный план (до железа) |
| `goal.md` | цель исполнения, редакция 3: задачи, критерии, техдолг |
| `progress-journal.md` | журнал исполнения с доказательствами, по времени |
| `design-1-sev-snp.md` | проектная записка: аттестация SEV-SNP, решения Р1–Р12 |
| `design-2-tdx.md` | TDX, Р13–Р19 |
| `design-3-sev-snp-addendum.md` | дополнение SEV-SNP, Р20–Р25 |
| `design-4-rejoin-mixed.md` | повторный вход и смешанный режим, Р26–Р27 |
| `design-5-offer-key-protection.md` | защита ключа от оператора, Р28–Р32, ТД-5 |

Ранние записки частично отменены поздними: запечатывание ключом процессора и
ключом агента dstack (Р9, Р24, ТД-2, ТД-3) снято решением Р30.
