# MVP: валидатор outbe-chain в защищённой VM (Intel TDX и AMD SEV-SNP)

Отчёт о работе 10–12 ноября 2026 года. Назначение: основа для планирования
следующих работ и база знаний о том, что сделано, что сломалось и почему.

Код: ветка `mvp-tdx-dstack`, коммиты `0e7fe0b62` и `c2efeeb97` поверх `main`
`607751fc9`. Каталог развёртывания в репозитории: `deploy/dstack/`.

## Итог

MVP признан успешным (решение владельца 2026-11-12).

Доказано на двух арендованных серверах (AMD EPYC 7413 и Intel Xeon 6527P):

- один образ VM запускает валидатор на TDX и на SEV-SNP;
- три сети из четырёх валидаторов работают из образа без входа (`prod`):
  только TDX, только SEV-SNP, смешанная 2 + 2 на двух серверах;
- после перезапуска VM валидатор сам регистрируется заново и получает ключ
  офферов от сети;
- VM с другим образом или изменённым манифестом ключ не получает;
- ключ офферов и состояние сервиса на диск не пишутся;
- файлы, подложенные оператором на диск данных, не запускаются;
- две сборки образа с нуля дают одинаковый `os_image_hash`.

Не доказано и не решено — см. `05-tech-debt.md`. Главное:

- при основании сети оператор валидатора-основателя может получить ключ (ТД-5);
- ключ живёт только в памяти: одновременный перезапуск всех валидаторов его
  уничтожает, а обновление образа означает новую сеть;
- защита не действует против физического доступа к серверу;
- образ `a9d2a455…d987a3` (r16) собран из рабочего дерева до коммита; образ
  из коммита `c2efeeb97` будет иметь другой хэш и ещё не собирался.

## Термины

| Термин | Значение |
|---|---|
| сервис (анклавный сервис) | процесс `outbe-tee-enclave`: держит ключ офферов, проверяет доказательства |
| ключ офферов | общий секрет сети для расшифровки офферов; единственное, что защищает MVP |
| манифест | `app-compose.json` dstack: что запускать в VM; его хэш привязан к отчёту процессора |
| измерение | значения, которые процессор фиксирует при запуске VM: образ и манифест |
| `dev` / `prod` | два варианта одного образа: с SSH и симулятором / без входа |
| бандл | архив данных валидатора: ключи, genesis, список узлов; программ не содержит |
| Р1…Р32 | решения проектных записок (см. `notes/`) |
| ТД-n | пункт техдолга |
