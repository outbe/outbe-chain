# Rights acceptance evidence

This map covers the approved implementation packages K00–K10 for Nod, Gem, Intex and their independent allocation and native-sink rules. It does not claim compliance for excluded credit or note products. The machine-readable case list is [`rights-acceptance-cases.json`](rights-acceptance-cases.json); the runner refuses missing or ignored Rust cases and verifies every selected Solidity case actually passed.

```sh
python3 scripts/verify-rights-acceptance.py --output /tmp/rights-proof --refresh
```

Install the repository's pinned Rust/nextest tools, run `npm ci` in both `mcp` and `contracts/intex`, and use Forge 1.7.1 with solc 0.8.30 (the committed transfer-fixture toolchain). `--refresh` removes only the mapped workspace packages' cached build artifacts, useful when sharing a Cargo target across worktrees. The output directory contains the compiled test inventory, full command logs, exit statuses, commit and manifest digest. It must remain outside the committed source tree. Individual phases are `rust`, `fixtures`, `solidity` and `client`; use separate output directories to retain separate reports.

Oracle policy is the approved 2/3 coverage, 28,800-second lookback and 3,600-second refresh. No additional observation-count or maximum-gap threshold and no dynamic policy activation is introduced. A Nod's logical issuance instant is the initial Lysis snapshot freeze; later request, activation or materialization clocks cannot reprice or requalify it. Genesis immediate qualification is fixed at issuance before actual first Worldwide Day creation.

Excluded acceptance IDs: A06–A11, A13, A19/A20/A22, A28–A30, A35, A40, A44/A45. Mixed A14/A16/A18/A21/A34/A36/A38/A41/A42/A43 cover only the named rows here. Direct payment acceptance does not close requirements that demand both payment rails. Epoch R43/R44 are excluded.

Call-term fixtures use PROD terms (28 calendar days, 21 strictly-above breach days) or explicitly sealed 21-of-N terms. DEV (3/2) is checked separately by profile-selection tests. Missing calendar days do not extend the window. Profile-selection and custom short-term conservation/transfer fixtures do not substitute for PROD timing acceptance.

## Additional conservation proofs

K06 adds five Gem kinds, a mixed Intex series, no-sale/partial-sale Desis, merchant-position expiry and failed/late bridge delivery plus reclaim. Each local failure matrix injects before and after every observed mutation, checks exact live/returned capacity, retries and proves a second pass credits zero. A bounded expiry sweep may safely commit partial progress; its durable remaining debt, rather than an unconditional error return, is the relevant invariant. The fixture values and exact executable names are recorded in the case manifest and K06 PR evidence.

K02 assigns whole-pot rounding residue to authenticated eligible leaf zero. Mixed/all-excluded generation production tests and weighted payout tests separately establish exclusion and distribution; a seeded certified root alone is not called a production opt-out witness. Existing active rounds lacking a recipient use authenticated recovery. Closed rounds remain closed.

K05 (`da4eb5da`, on K03) preserves entry/floor/call/cost through certified activation and delayed materialization. Its append-only Genesis privilege flag is atomic with issuance. A legacy zero creation-counter slot with a retained active/closed day fails closed, and existing unflagged Gems are not retroactively granted the privilege.

## Evidence boundaries

The EVM transfer test runs real ERC-1155 runtime bytecode installed directly and initialized against empty storage; it does not test proxy deployment or a remote chain. Solidity bridge tests use an authenticated mock gateway. Confidential-ledger mining tests use the deterministic test enclave, not SGX hardware attestation.

Mining failures verify the atomic storage-checkpoint rollback boundary and retries. They do not claim a physical node stop and RocksDB reopen around mining. PoW and ledger MAC have distinct responsibilities: PoW identifies the right/owner/sequence, while the MAC authorizes account/op/amount/op-nonce/chain. A solved PoW nonce is not a cross-chain mint authorization. Equal-load rights of the same owner can share a valid amount authorization when each right's PoW is solved; this is recorded as the current contract, not silently changed to a new preimage version.

Governance Error refund tests include a valid synthetic registered target and persisted legacy Error recovery. No admissible production bonded-Error witness was established for the baseline StablecoinFactory target. The tests prove the terminal refund contract, atomicity and exactly-once handling; they do not establish production reachability of every composite C38 scenario.

Linux snapshot-export proof belongs to K00 CI. macOS deliberately refuses the Linux `openat2` donor guard; a local unsupported-platform test does not establish successful Linux export. Existing ignored tests and these platform boundaries must remain visible in reports.

Q016 auction `units` encoding has a separate requirement mapping in the Solidity manifest. Its signature/replay tests verify the signed wire contract; they are not counted as A39 Limit/Allocation evidence.
