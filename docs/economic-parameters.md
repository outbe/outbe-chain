# Outbe Economic Parameters

The economic subset of [`parameters.md`](parameters.md): 276 parameters that set emission, allocation, rewards, staking and slashing, contract prices and settlement, Credis, and price formation. Read from commit [`4c2a09f`](https://github.com/outbe/outbe-chain/tree/4c2a09f67c50a9b36990182a993c55e5b6c339aa); line links may drift as the code changes.

Values are the mainnet (PROD) profile unless a row says otherwise; test networks default to the DEV profile (see *Genesis profiles*). **★** marks headline parameters; **⚠** marks a note that flags a mismatch.

**How a value can change** — **Constant**: compiled in, needs a release. **Genesis**: set in the genesis file. **On-chain**: changed by governance or an admin role. **Config**: off-chain default. **Solidity**: contract constant. **Derived**: computed from other parameters.

## Headline numbers

### Floor, call and settlement · mainnet profile

| Parameter | Value | Detail |
|---|---|---|
| Floor price | **1.08 × entry** | +8% over the reference-currency entry price. Same for Nod, Intex and Gem. |
| Qualification | **1 day above floor** | One finalized UTC-day COEN price above the floor opens settlement. No holding period in code. |
| Call price · Intex, Gem | **2.28 × entry** | +128%. The canon states 1.64×. |
| Call price · Nod | **3.56 × entry** | +256%. Nod buckets are called and forfeited like Intex and Gem. |
| Call price · Credis | **1.64 × anchor** | +64% over the previous day's COEN price when the position opens. |
| Call trigger | **21 of 28 days** | UTC days with the daily COEN price strictly above the call price. The canon states 21 of 30. |
| Call notice | **7 days** | Time to settle after a call. Unsettled rights are forfeited and their load returns to the Promis pool. |
| SRA Gem cost | **64%** | SRA-class Gems settle at 64% of the full Cost Amount; other Gem types pay 100%. |
